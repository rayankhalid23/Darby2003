# 05 — الاشتراكات الحالية

## جدول `active_subscriptions` (الموديل `ActiveSubscription`)

يُنشأ سجل واحد لكل طفل عند قبول السائق لطلب الاشتراك. **المصدر:** `migrations_v2/2026_09_04_100020` + تمديدات (`route_id`, `status` enum) ثم تطبيع كبير حذف تكرارات: `2026_09_07_000003` (إضافة `request_child_id` وحقول الإلغاء)، `2026_09_07_183714` (حذف `start_date/end_date/school_id` الميتة)، `2026_09_07_215107` (حذف `child_id`/`driver_id`/`parent_id` كأعمدة فعلية — أصبحت مُشتقة).

| اسم الحقل | النوع | إلزامي؟ | القيمة الافتراضية | مفتاح أجنبي | الوصف |
|---|---|---|---|---|---|
| id | bigint (PK) | نعم | — | — | المعرّف |
| subscription_request_id | bigint | نعم | — | FK → `requests.id` (cascade) | طلب الاشتراك الأصلي |
| request_child_id | bigint | لا | null | FK → `request_children.id` (cascade) | بند الطفل المصدر لبيانات الطفل/المدرسة/السعر |
| route_id | bigint | لا | null | FK → `routes.id` (nullOnDelete) | خط السير المخصص |
| pickup_lat / pickup_lng / pickup_label | decimal / string(255) | لا | null | — | نقطة الاستلام |
| dropoff_lat / dropoff_lng / dropoff_label | decimal / string(255) | لا | null | — | نقطة التسليم |
| pickup_time / dropoff_time | time | لا | null | — | أوقات الاستلام/التسليم |
| sort_order | integer | نعم | 0 | — | ترتيب الموقف ضمن خط سير السائق |
| status | enum('active','paused','completed','cancelled','suspended_unpaid','terminated') | نعم | 'active' | — | حالة الاشتراك |
| cancelled_at | timestamp | لا | null | — | تاريخ الإلغاء |
| cancelled_by | string(20) | لا | null | — | من ألغى: `parent` \| `driver` \| `admin` \| `system` |

> **مهم:** `child_id`, `driver_id`, `parent_id`, `school_id` **ليست أعمدة فعلية** في هذا الجدول — يعرضها الموديل عبر خصائص محسوبة (accessors) تمرّ عبر `requestChild` ثم `subscriptionRequest`، بحيث تبقى القراءة (`->child_id` مثلاً) تعمل بشفافية دون تخزين مكرر.

### العلاقات

| العلاقة | النوع | الجدول/الموديل المقابل |
|---|---|---|
| subscriptionRequest() | belongsTo | SubscriptionRequest |
| requestChild() | belongsTo | RequestChild |
| route() | belongsTo | Route |
| child() / driver() / parent() / school() | belongsTo (عبر accessor) | Child / Driver / User / School |

**Scopes متاحة:** `forDriver()`, `forParent()`, `forChild()`, `forChildren()`, `excludingChildren()`.

### إلغاء الاشتراك وفق الإجراءات المعتمدة

يُنفَّذ عبر `SubscriptionRequestService::cancelActiveSubscriptionByParent()` أو `cancelActiveSubscriptionByDriver()`، وتشمل الخطوات:

1. تحديث `status` إلى `cancelled` (مع منع الإلغاء إن كانت الحالة `cancelled` أو `completed` مسبقًا).
2. تحرير مقاعد الحجز في `driver_seat_slots` (`releaseSeatsForSubscription`).
3. استرداد الأموال المُحتجزة (`refundHeldFundsOnCancellation`) — تختلف سياسة الاسترداد: إلغاء السائق يُرجع كامل المبلغ لولي الأمر، بينما إلغاء ولي الأمر يخضع لسياسة تعويض (انظر [07](07-المحفظة-الإلكترونية-والمالية.md)، جدول `platform_finances`).
4. إزالة الطفل من خط سير السائق الحي (`MasterRouteStopSyncService`).
5. إرسال إشعار للطرف الآخر.

### استخدام هذا الكيان في وظائف التطبيقين

- **عرض قائمة/تفاصيل الاشتراكات الحالية** (ولي الأمر والسائق): قراءة `active_subscriptions` مع `subscriptionRequest`/`requestChild`/`route`.
- **إلغاء الاشتراك** (ولي الأمر والسائق): تحديث الحالة وفق الخطوات أعلاه.
