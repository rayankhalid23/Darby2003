### العلاقات — `app/Models/Shared/Trip.php`

| العلاقة | النوع | الجدول/الموديل المقابل |
|---|---|---|
| driver() | belongsTo | Driver |
| route() | belongsTo | Route |
| events() | hasMany | TripEvent |
| tracking() | hasMany | TripTracking |
| stops() | hasMany | TripStop (مرتبة حسب `sequence_order`) |

| activeSubscriptions() | hasMany | ActiveSubscription (مربوطة عبر `route_id` وليس مفتاحًا أجنبيًا مباشرًا) |
